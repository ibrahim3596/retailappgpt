# RetailPOS V2

Clean rebuild of RetailPOS using the agreed product specification and UI/UX direction.

## Current milestone
UI/UX foundation and Android project scaffold only.

## Principles
- Shopkeeper-first workflows
- Fast billing
- Offline-first architecture
- One coherent design system
- Business logic separated from UI
- Cloud identity and sync added only after the local foundation is stable

The previous implementation remains on `main` as a reference archive. `retailpos-v2` is the clean development line.
